# api-gateway-serverless

api-gateway con hhtp-APIs

💸 Ahorro de Costes y Escalabilidad Automática: El beneficio más inmediato es el modelo de pago por uso - Lambda.

🛡️ Capa de Seguridad Centralizada: Actúa como un guardia de seguridad para tu backend.

🏗️ Orquestación de Microservicios: En lugar de tener una función monolítica que lo hace todo, puedes tener varias funciones pequeñas y especializadas (una para pagos, facturacion, usuarios, etc)
